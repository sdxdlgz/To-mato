# To-mato 🍅

一个简洁优雅的番茄钟 + 待办事项管理应用，帮助你专注工作，提高效率。

## ✨ 特性

- 🍅 **番茄钟计时器** - 1-180分钟可调专注时长，自动循环
- ⏱️ **正计时功能** - 无上限正计时器，适合长时间专注
- ✅ **任务管理** - 添加、编辑、删除任务，支持优先级标记
- 📊 **完成度统计** - 可视化任务完成进度
- 📅 **日历视图** - 查看每日完成的任务记录
- 📈 **专注时间统计** - 记录每日专注时长
- 🎯 **目标倒计时** - 设置重要日期倒计时
- 📤 **分享功能** - 一键分享专注成果和完成任务
- 🌐 **中英文切换** - 支持中英文界面切换
- 🎨 **多主题切换** - 6种配色主题 + 暗黑模式
- 📱 **响应式设计** - 完美适配桌面端和移动端
- 💾 **本地存储** - 数据保存在浏览器，无需注册

## 🚀 快速开始

### 在线体验

访问：https://sdxdlgz.github.io/To-mato/

### 本地运行

1. 克隆仓库
```bash
git clone https://github.com/你的用户名/to-study.git
cd to-study
```

2. 使用任意 HTTP 服务器运行
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve public
```

3. 打开浏览器访问 `http://localhost:8000`

## 🎯 使用方法

1. **添加任务** - 输入任务内容，选择优先级，点击添加
2. **开始专注** - 点击"开始"按钮启动番茄钟（可设置1-180分钟）
3. **正计时** - 使用正计时功能进行无限时长的专注
4. **完成任务** - 勾选任务复选框标记完成
5. **查看记录** - 在日历中查看已完成的任务
6. **分享成果** - 点击分享按钮分享今日专注时长和完成任务
7. **切换主题** - 点击右下角画笔图标选择喜欢的主题
8. **切换语言** - 在主题面板中切换中英文界面
